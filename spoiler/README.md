# 스포 방지 (카카오)

## 문제 요약

메시지에서 스포 방지 구간을 왼쪽부터 순서대로 클릭할 때, **중요한 단어**의 수를 반환.

## 핵심 정의

### 스포일러 단어
- 단어의 문자 인덱스 중 **하나라도** 스포 방지 구간에 포함되면 스포일러 단어

### 중요한 단어 (아래 조건 모두 충족)
1. 스포일러 단어여야 함
2. **비스포일러 구간**에 한 번도 등장한 적 없어야 함
3. **이전에 공개된 스포일러 단어**와 중복되지 않아야 함

### 단어 공개 시점
- 스포 방지 구간을 클릭하면, 그 구간이 **마지막으로 겹치는 구간**인 단어들이 공개됨
- 동시에 여러 단어가 공개되면 왼쪽부터 순서대로 중요도 판단

## 입력

| 매개변수 | 설명 |
|---|---|
| `message` | 메시지 문자열 (알파벳 소문자, 숫자, 공백) |
| `spoiler_ranges` | `[start, end]` 배열. 비겹침, start 기준 오름차순 정렬 |

## 제한사항

- 1 ≤ message 길이 ≤ 20,000
- 1 ≤ spoiler_ranges 길이 ≤ 1,000
- 모든 구간은 서로 겹치지 않음

## 입출력 예

| message | spoiler_ranges | result |
|---|---|---|
| `"here is muzi here is a secret message"` | `[[0,3],[23,28]]` | `1` |
| `"my phone number is 01012345678 and may i have your phone number"` | `[[5,5],[25,28],[34,40],[53,59]]` | `4` |

## 예제 풀이 (예제 2)

```
비스포일러 단어: my, number, is, and, have, your

클릭 순서:
[5,5]   → phone 공개        → 중요 O (count=1)
[25,28] → 01012345678 공개  → 중요 O (count=2)
[34,40] → may, i 공개       → 둘 다 중요 O (count=4)
[53,59] → phone, number 공개→ phone은 중복, number는 비스포일러에 존재 → 둘 다 중요 X
```
