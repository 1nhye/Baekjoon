# 신호등 - 정전 발생 시각 찾기

## 문제 설명

어떤 도로에 차량 신호등이 n개 있습니다. 모든 신호등은 항상 **초록불 → 노란불 → 빨간불** 순서로 반복되며, 각 신호의 지속 시간은 신호등마다 다릅니다.

- 시간은 **1초부터 시작**
- 각 신호등은 처음에 **초록불** 상태로 시작

**모든 신호등이 동시에 노란불이 되면 정전이 발생합니다.**

---

## 함수 시그니처

```python
def solution(signals):
    pass
```

---

## 제한 사항

- `2 ≤ signals의 길이 = n ≤ 5`
- `signals`의 원소는 `[G, Y, R]` 형태의 길이 3인 정수 배열
  - 순서대로 초록불, 노란불, 빨간불의 지속 시간
- `1 ≤ G, Y, R ≤ 18`
- `3 ≤ G + Y + R ≤ 20`

---

## 입출력 예

| signals | result |
|---|---|
| `[[2, 1, 2], [5, 1, 1]]` | `13` |
| `[[2, 3, 2], [3, 1, 3], [2, 1, 1]]` | `11` |
| `[[3, 3, 3], [5, 4, 2], [2, 1, 2]]` | `193` |
| `[[1, 1, 4], [2, 1, 3], [3, 1, 2], [4, 1, 1]]` | `-1` |

---

## 예시 설명

### 예시 1 - `[[2, 1, 2], [5, 1, 1]]` → `13`

| 시간 | 1~2 | 3 | 4~5 | 6~10 | 11 | 12 | 13 |
|---|---|---|---|---|---|---|---|
| 신호등 1 | 초록 | **노란** | 빨간 | 초록 | 빨간 | 빨간 | **노란** |
| 신호등 2 | 초록 | 초록 | 초록 | 초록 | 초록 | **노란** | **노란** |

13초에 두 신호등이 처음으로 모두 노란불이 됩니다.

### 예시 4 - `[[1, 1, 4], [2, 1, 3], [3, 1, 2], [4, 1, 1]]` → `-1`

모든 신호등이 동시에 노란불이 되는 경우가 없으므로 `-1`을 반환합니다.
