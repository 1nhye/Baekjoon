# split() vs split(' ')

## 핵심
단어로 나눌 때는 **`split()`** 사용. `split(' ')` 쓰면 위험.

| | `split()` | `split(' ')` |
|---|---|---|
| 앞뒤 공백 | 자동 제거 | 빈 문자열 생성 |
| 연속 공백 | 하나로 처리 | 빈 문자열 생성 |

## 예시
```python
" a a".split(' ')  # ['', 'a', 'a']  ← 위험!
" a a".split()     # ['a', 'a']      ← 안전
```

## 언제 `split(' ')` 써도 되나?
구분자가 정확히 공백 한 칸임을 **보장**할 때만.
