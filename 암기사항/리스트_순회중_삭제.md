# 리스트 순회 중 삭제 금지

## 문제
리스트를 `for`로 순회하면서 동시에 삭제하면 원소가 건너뛰어짐.

```python
# 위험!
for x in lst:
    if condition:
        del lst[lst.index(x)]  # 내부 인덱스가 밀려서 원소 스킵
```

## 해결
```python
# 안전: 리스트 컴프리헨션으로 새 리스트 생성
lst = [x for x in lst if not condition]
```

## 단, 다른 리스트를 수정하는 건 괜찮음
```python
for x in lst_a:          # lst_a 순회
    if x in lst_b:
        del lst_b[...]   # lst_b 수정 → 안전
```
