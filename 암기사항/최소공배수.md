# 코테 암기사항

## 최소공배수 (LCM)

### 공식
```
LCM(a, b) = a * b // GCD(a, b)
```

### 코드 (프로그래머스 기본)
```python
import math

def lcm(a, b):
    return a * b // math.gcd(a, b)
```

### 여러 수의 LCM
```python
import math

def lcm(a, b):
    return a * b // math.gcd(a, b)

# 리스트의 모든 수에 대한 LCM
result = nums[0]
for i in range(1, len(nums)):
    result = lcm(result, nums[i])
```

> 참고: Python 3.9+에서는 `math.lcm(a, b)` 사용 가능하지만, 프로그래머스는 3.8 기준이므로 위 방식 사용.
